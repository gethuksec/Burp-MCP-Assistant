🎯 Burp MCP Tools Reference

Quick reference for all 21 Burp MCP tools

HTTP Request Execution

send_http1_request
Issues an HTTP/1.1 request and returns the response
Parameters: targetHostname, targetPort, usesHttps, content
send_http2_request
Issues an HTTP/2 request and returns the response
Parameters: targetHostname, targetPort, usesHttps, pseudoHeaders, headers, requestBody

Burp Tools Integration

create_repeater_tab
Creates a new Repeater tab with specified HTTP request
Parameters: targetHostname, targetPort, usesHttps, content, tabName
send_to_intruder
Sends HTTP request to Intruder
Parameters: targetHostname, targetPort, usesHttps, content, tabName

Encoding/Decoding

url_encode
URL encodes the input string
Parameters: content
url_decode
URL decodes the input string
Parameters: content
base64_encode
Base64 encodes the input string
Parameters: content
base64_decode
Base64 decodes the input string
Parameters: content
generate_random_string
Generates random string of specified length and character set
Parameters: length, characterSet

Configuration Management

output_project_options
Outputs current project-level configuration in JSON format
output_user_options
Outputs current user-level configuration in JSON format
set_project_options
Sets project-level configuration in JSON format
Parameters: json
set_user_options
Sets user-level configuration in JSON format
Parameters: json

History & Monitoring

get_proxy_http_history
Displays items within the proxy HTTP history
Parameters: count, offset
get_proxy_http_history_regex
Displays items matching regex within proxy HTTP history
Parameters: regex, count, offset
get_proxy_websocket_history
Displays items within proxy WebSocket history
Parameters: count, offset
get_proxy_websocket_history_regex
Displays items matching regex within WebSocket history
Parameters: regex, count, offset

State Management

set_task_execution_engine_state
Sets state of Burp's task execution engine (paused or running)
Parameters: running (boolean)
set_proxy_intercept_state
Enables or disables Burp Proxy Intercept
Parameters: intercepting (boolean)

Editor Integration

get_active_editor_contents
Outputs contents of user's active message editor
set_active_editor_contents
Sets content of user's active message editor
Parameters: text
